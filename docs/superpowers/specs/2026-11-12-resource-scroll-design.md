# Resource scroll design

## Intent

Make the resources page feel dimensional and memorable while keeping every file and link fast to find.

## Direction

- Replace the custom cursor with three vertically stacked resource panels.
- Give the stage a deep perspective so panels tilt in, become level and prominent at the viewport center, then tilt away.
- Use one vivid shadow color per panel; color appears through depth and light rather than gradients.
- Add a prominent search field that filters all resource titles immediately and announces the remaining result count.
- Increase outer and internal spacing, while keeping the mobile version compact and disabling motion for reduced-motion users.

## Alternatives considered

- Animate every individual row: more motion, but makes scanning and clicking harder.
- Keep the three-column layout and add parallax: too little vertical travel for the requested rolling-through feeling.
- Chosen: stacked category panels, because the scroll itself becomes the interaction and the information hierarchy stays clear.
